# 关于项目

## 项目简介

Axiom 是一个面向 AI 编程协作的工程化系统，通过 `.agent/` 目录把记忆、流程和门禁落到项目内，让 AI 在多轮开发中保持连续性与可追踪性。

你可以把它理解为：给 AI 编程助手加上一套可执行的团队工作方式。
