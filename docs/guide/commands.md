# 命令参考

## 核心命令

| 命令 | 说明 |
|---|---|
| `/start` | 加载上下文并恢复会话 |
| `/status` | 查看系统仪表盘 |
| `/feature-flow` | 启动开发交付流程（兼容入口） |
| `/analyze-error` | 触发错误分析与修复 |
| `/reflect` | 记录复盘与学习 |
| `/evolve` | 整理知识与模式 |
| `/suspend` | 暂停并保存当前会话 |
| `/rollback` | 回滚到检查点 |

## 系统级命令

| 命令 | 说明 |
|---|---|
| `/meta` | 修改 Axiom 自身规则 |
| `/export` | 导出可分享副本 |
| `/knowledge [关键词]` | 查询知识库 |
| `/patterns [关键词]` | 查询模式库 |

## 推荐工作流

1. `/start`
2. 输入需求
3. `/status` 跟进进度
4. 失败时 `/analyze-error`
5. 完成后 `/reflect`，收尾 `/suspend`

## 质量门禁

- 任务完成前必须通过编译/测试
- 重大错误最多重试 3 次后进入阻塞处理
- 关键变更需可追溯（状态、日志、检查点）
