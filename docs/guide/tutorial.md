# 实战教程：从需求到交付

本教程演示一条完整链路：需求 -> 评审 -> 实现 -> 验证 -> 复盘。

## Step 1: 提需求

示例输入：

```text
实现一个用户注册功能，包含邮箱格式校验、密码强度校验、提交失败提示和对应测试。
```

## Step 2: 让系统进入流水线

可显式触发：

```text
/feature-flow
```

系统会按工作流推进（评审、拆解、实现）。

## Step 3: 处理中途错误

如果出现编译/测试失败，输入：

```text
/analyze-error
```

并粘贴完整错误日志。系统会按“收集日志 -> 根因分析 -> 修复/回滚/跳过”的流程处理。

## Step 4: 查看状态

```text
/status
```

重点观察：

- 当前任务状态
- 完成率与队列
- 最近检查点

## Step 5: 结束并沉淀

任务完成后执行：

```text
/reflect
```

按需执行：

```text
/evolve
```

## 验收标准

- 需求有可追踪的执行记录
- 失败路径有修复或明确阻塞结论
- 关键经验进入记忆系统
