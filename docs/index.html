Core Capabilities

三层结构，保证 AI 行为可追踪、可复盘、可演进

记忆层

保存项目决策、用户偏好与活动上下文，避免每轮对话从零开始。

  • 长期决策沉淀
  • 跨会话恢复任务
  • 知识与模式自动收割

流程层

把需求评审、任务拆解、实现、验证串成闭环，门禁依赖可验证产物。

  • Manifest-Driven
  • Evidence-Based Gates
  • 增量交付可回滚

协作层

统一适配不同 AI 工具，保持一致指令语义与团队协作节奏。

  • 多模型协同
  • 兼容入口 `.agents/`
  • 低侵入接入业务代码

Workflow

从 `/start` 到交付，全流程自动接力

  1. 01加载记忆与上下文：恢复任务状态与项目约束
  2. 02需求评审与 PRD：先定目标，再拆任务
  3. 03编码执行与自检：失败最多 3 次重试并熔断
  4. 04测试通过后交付：结果记录、知识收割、可持续进化

跨天开发保持上下文连续，经验自动沉淀为团队资产。

FAQ

常见问题

会污染业务代码吗？

不会。Axiom 主要落在 `.agent/` 和文档目录，对业务代码侵入很低。

支持哪些技术栈？

内置 Flutter / React / Vue / Django / Express / Gin 模板，也支持自定义。

如何快速体验？

安装后在项目内输入 `/start`，再按 `/feature-flow` 走一遍完整交付链路即可。
