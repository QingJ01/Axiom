# 版本发布

## 起始版本

- 当前起始版本：`0.0.1`

## 版本策略

- `0.0.x`：快速迭代与功能验证
- `0.1.0`：核心工作流稳定可用
- `1.0.0`：接口与流程对外稳定

## 发布前检查

1. 安装脚本可运行（`setup.sh` / `setup.ps1`）
2. `/start`、`/status`、`/feature-flow` 可正常触发
3. 关键记忆文件可读写
4. 文档与行为一致
5. 更新版本号与变更日志

更新日志见：`docs/reference/changelog.md`

## 建议发布节奏

- 每次发布只包含一组可验证能力
- 先在测试项目跑一次完整任务链路
- 失败案例写入 `Known Issues`
